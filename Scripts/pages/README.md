# Páginas do painel

Este README foi redigido com apoio de IA (Claude Opus 5.5 e Claude Haiku 5.5) e revisado pelo autor.

Objetivo: uma página por tema. O menu lista as páginas na ordem do nome do arquivo.

- `1_Panorama_setorial.py`: participação de agropecuária, indústria, serviços e impostos no PIB, nos últimos quatro trimestres (SIDRA).
- `2_Serie_historica.py`: série do indicador 9.2.1 (indústria de transformação no PIB) com seletor de anos (API ou leitura direta).
- `3_Comparacao_internacional.py`: comparação com outros países a partir do CSV do DataBank, enviado pelo usuário.
- `4_Corpus_e_resumos.py`: metas do ODS 9, nuvem de palavras e corpus. A aba **Resumo** gera resumos com o modelo de linguagem local pela API, de metas do ODS 9, de referências e da introdução de Oreiro e Feijó (2010), em português.
- `5_Fontes_e_metodo.py`: fontes, ressalvas de método e verificação dos critérios de sucesso do charter.
